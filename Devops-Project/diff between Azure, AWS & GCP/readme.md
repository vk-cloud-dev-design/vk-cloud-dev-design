# ☁️ Azure vs AWS vs GCP

> 🚀 A quick comparison of the three leading public cloud platforms.

---

## 🌐 Cloud Providers

| | 🔵 Azure | 🟠 AWS | 🔵 GCP |
|---|---|---|---|
| **Provider** | Microsoft | Amazon | Google |
| **Compute** | Virtual Machines | EC2 | Compute Engine |
| **Kubernetes** | AKS | EKS | GKE |
| **Object Storage** | Blob Storage | S3 | Cloud Storage |
| **Serverless** | Azure Functions | Lambda | Cloud Functions |
| **IaC** | ARM / Bicep / Terraform | CloudFormation / Terraform | Terraform |
| **DevOps** | Azure DevOps | CodePipeline | Cloud Build |
| **Container Registry** | ACR | ECR | Artifact Registry |
| **Monitoring** | Azure Monitor | CloudWatch | Cloud Monitoring |

---

## ⚔️ Key Differences

### 🔵 Microsoft Azure
- 🏢 Strong **enterprise & Microsoft ecosystem**
- 🔗 Excellent integration with **Microsoft 365, Active Directory & Windows**
- 🛠️ Strong **Azure DevOps** integration
- ☸️ AKS for managed Kubernetes

### 🟠 Amazon AWS
- 🌍 Broad global cloud ecosystem
- 🧩 Large selection of cloud services
- ⚡ Strong infrastructure flexibility
- ☸️ EKS for managed Kubernetes

### 🔵 Google Cloud (GCP)
- 🤖 Strong **AI & Machine Learning**
- 📊 Excellent data & analytics capabilities
- ☸️ GKE with strong Kubernetes ecosystem
- 🌐 Strong cloud networking capabilities
